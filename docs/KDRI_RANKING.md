# KDRI 부족 영양소 및 원재료 랭킹

## 기준 자료

- 보건복지부·한국영양학회, `2025 한국인 영양소 섭취기준`, 2025
- 권장섭취량이 설정된 영양소는 권장섭취량(RNI)을 사용한다.
- 식이섬유와 칼륨은 충분섭취량(AI)을 사용한다.
- 현재 대상은 단백질, 식이섬유, 칼슘, 철, 칼륨, 비타민 A, 비타민 C이다.

공식 자료와 정오표 안내:
https://www.kns.or.kr/fileroom/fileroom_view.asp?BoardID=Kdr&idx=167

## 프로필 해석

- 현재 사용자 프로필에는 생년만 있으므로 기준 날짜의 연도에서 생년을 뺀 값을 나이로 사용한다.
- 생년 또는 성별이 없거나 계산된 나이가 1세 미만이면 KDRI 계산을 거부한다.
- `PREFER_NOT_TO_SAY`는 부족을 과대평가하지 않도록 같은 연령대 남녀 값 중 더 낮은 값을 영양소별로 사용한다. 이는 KDRI가 별도로 제시한 기준이 아니라 서비스의 파생 정책이다.
- 임신·수유 여부를 저장하지 않으므로 임신부·수유부 부가량은 적용하지 않는다.

## 일일 영양 합산

- 날짜 경계는 `Asia/Seoul` 기준으로 계산한 뒤 DB 저장 기준인 UTC `LocalDateTime`으로 변환한다.
- `CONFIRMED`, `COMPLETED` 식사만 합산한다.
- 영양 값이 `NULL`인 항목은 알려진 값의 합산에서 제외하며, 하루 전체에 알려진 값이 없으면 0으로 계산한다.

## 부족 영양소

- 부족량은 `max(기준값 - 당일 합계, 0)`이다.
- 부족 비율은 `부족량 / 기준값`이다.
- 부족 비율이 가장 높은 영양소를 대표 영양소로 선택한다.
- 비율이 같으면 `PROTEIN → FIBER → CALCIUM → IRON → POTASSIUM → VITAMIN_A → VITAMIN_C` 순서를 사용한다.
- 모든 기준을 충족하면 대표 영양소와 원재료 후보를 반환하지 않는다.

## 원재료 랭킹

- 활성 상태이며 `food_type=INGREDIENT`, `is_recommendation_candidate=true`인 식품만 사용한다.
- 모든 영양값을 서비스 표준인 1인분 기준으로 환산한다.
- 대표 부족 영양소의 1인분당 함량을 우선 정렬 기준으로 사용한다.
- 동점이면 전체 부족 영양소 보완 점수, 원재료명, food ID 순으로 정렬한다.
- 정규화한 원재료명이 같은 후보는 가장 높은 한 건만 남긴다.
- 사용자 비선호 원재료와 알레르기 원재료는 제외한다.

## 알레르기 필터의 한계

현재 식품 카탈로그에는 구조화된 식품-알레르기 관계가 없다. 따라서 식품 표시 대상 알레르기 원재료의 표준 코드와 원재료명 키워드를 이용해 보수적으로 제외한다. 알 수 없는 알레르기 코드가 하나라도 있으면 안전 여부를 판단할 수 없으므로 후보 목록 전체를 비운다.

이 필터는 의료적 안전을 보증하는 최종 장치가 아니다. 향후 구조화된 알레르기 매핑 테이블을 도입하면 키워드 정책을 교체해야 한다.

알레르기 표시 대상 참고:
https://www.law.go.kr/LSW/cgmExpcInfoP.do?cgmExpcDatSeq=419496&mode=2&ofiClsCd=350123

## 요리 매핑 연결

`RecommendationPlanningService`가 전체 원재료 랭킹에서 안전한 원재료를 최대 3개 선택한다. DB에 안전한 활용 요리가 2개 이상 있으면 해당 매핑을 사용하고, 부족하면 OpenAI가 그 원재료의 요리만 2~3개 보완한다. DB 원재료로 요청 개수를 채우지 못한 경우에만 OpenAI 원재료 fallback을 사용한다. 새 추천은 사용자의 직전 추천 원재료를 제외하며, 새로고침은 같은 추천에서 이전에 노출한 원재료를 누적 제외한다. 상세 매핑 및 안전 정책은 `INGREDIENT_DISH_MAPPING.md`를 따른다.

추천 저장·응답 API와 실제 AI 설명·재정렬은 후속 작업에서 이 결과를 사용해 완성한다.
